# 한국주식 정밀분석 (index.html 단일 웹앱)

[korea-stock-analyzer-mcp](https://github.com/Mrbaeksang/korea-stock-analyzer-mcp)(Apache-2.0, Python MCP 서버)의
분석 엔진을 브라우저에서 그대로 돌아가도록 옮긴 것입니다. 설치할 프로그램이 없고,
GitHub Pages 주소 하나로 휴대폰에서 바로 씁니다.

원본의 원칙을 그대로 지켰습니다 — **데이터가 없으면 없다고 표시하고, 추정치를 채워 넣지 않습니다.**

---

## 1. 무엇이 필요한가

| 구성 | 역할 | 비용 |
|---|---|---|
| GitHub Pages | `index.html` 호스팅 | 무료 |
| Cloudflare Worker | DART·시세 중계, 인증키 보관 | 무료 (하루 10만 요청) |
| DART OpenAPI 키 | 재무제표·공시 조회 | 무료 (하루 2만 건) |

Worker가 왜 필요하냐면, DART와 시세 서버가 브라우저에 CORS 허용 헤더를 주지 않아
`index.html`이 직접 부르면 전부 차단되기 때문입니다. 또 DART 인증키를 공개 저장소에
넣으면 남이 가져다 쓰므로, 키는 Worker 환경변수에만 둡니다.

---

## 2. DART 인증키 발급 (3분)

1. <https://opendart.fss.or.kr> 접속 → 인증키 신청
2. 이메일 인증 → 발급된 40자리 키 복사

---

## 3. Cloudflare Worker 배포 (5분)

1. <https://dash.cloudflare.com> → **Workers & Pages** → **Create** → **Start from Hello World**
2. 이름을 `ksa-proxy` 로 정하고 배포
3. **Edit code** → 기존 내용 전부 지우고 `worker.js` 붙여넣기 → **Deploy**
4. Worker 화면 → **Settings** → **Variables and Secrets** → **Add**
   - Type: **Secret**
   - Name: `DART_API_KEY`
   - Value: 발급받은 키
   - 저장 후 **Deploy** 한 번 더
5. 주소 확인: `https://ksa-proxy.<계정>.workers.dev`

브라우저로 그 주소 뒤에 `/health` 를 붙여 열었을 때
`{"ok":true, "dart_key":"설정됨", ...}` 이 나오면 성공입니다.

---

## 4. GitHub Pages 배포 (3분)

1. 새 저장소 생성 (예: `korea-stock-analyzer`) — **Public**
2. `index.html` 과 `.nojekyll` 업로드 → Commit
3. **Settings** → **Pages** → Source: `Deploy from a branch` → Branch: `main` / `(root)` → Save
4. 1~2분 뒤 주소가 열립니다:
   `https://<계정>.github.io/korea-stock-analyzer/`

`worker.js` 와 `README.md` 는 같이 올려도 되고 안 올려도 됩니다. 화면에는 영향이 없습니다.

---

## 5. 첫 실행

1. 배포된 주소를 엽니다
2. 아래쪽 **연결 설정** 을 펼쳐 Worker 주소를 넣고 **저장**
3. **연결 점검** 을 눌러 네 줄 모두 `✔` 인지 확인
4. 종목명이나 6자리 코드를 넣고 **분석**

휴대폰에서는 브라우저 메뉴의 «홈 화면에 추가»를 하면 앱처럼 열립니다.
주소 끝에 `#005930` 을 붙이면 해당 종목이 바로 열리므로, 자주 보는 종목은
그 상태로 즐겨찾기 해두면 편합니다.

## 6. 화면 구성

| 영역 | 내용 |
|---|---|
| 시세 헤더 | 현재가·등락(적=상승/청=하락)·52주 고저·거래량·1년 종가 스파크라인 |
| 시총 정합 배지 | 주가×발행주식수 와 보고 시가총액을 대조. 2% 초과 시 «편차» 표시 |
| 멀티플 게이지 | PER·PBR 반원 게이지. 붉은 호는 통상적 고평가 구간 |
| 연간 재무제표 | 5개년 실측치 + 비율 + 항목별 추세 스파크라인 |
| 3시나리오 | 비관·중립·낙관 가치 범위와 현재가 위치. 가정을 전부 표기 |
| 재무 적신호 | 6종 검사를 «이상 없음 / 경고 / 검사 불가» 3상태로 표시 |
| 최근 공시 | 90일 공시 목록, 위험 키워드 강조 |

**검사 불가**를 굳이 자리 차지하게 남겨둔 것이 이 앱의 핵심입니다.
확인하지 못한 항목을 «문제 없음»으로 섞지 않기 위해서입니다.

## 7. 데이터 출처와 한계

| 데이터 | 출처 | 한계 |
|---|---|---|
| 재무제표 | DART 사업보고서 (연결 우선, 별도 폴백) | 연간만, 분기 없음 |
| 발행주식수 | DART 주식의 총수 현황 | 보통주 기준 |
| 시세·52주 고저 | 야후 파이낸스 일봉 | 실시간 아님 (종가 기준) |
| 보고 시가총액 | 네이버 금융 | 교차검증 용도 |
| FCF | 영업CF − 유형자산 취득 | **근사치** — 무형자산·리스 미포함 |

목표 멀티플 8/10/12배는 **데이터가 아니라 보수적 고정 가정**이며 화면에도 그렇게 적혀 있습니다.

## 8. 문제가 생기면

| 증상 | 원인 / 조치 |
|---|---|
| «프록시 주소가 설정되지 않았습니다» | 연결 설정에 Worker 주소 입력 |
| 연결 점검에서 `/corps` 실패 | `DART_API_KEY` 미설정 또는 오타. Worker Settings 확인 |
| 「DART 일일 호출 한도 초과」 | 하루 2만 건 소진. 다음 날 자동 해제 |
| 시세만 «없음» | 야후에 해당 종목이 없는 경우 (일부 우선주·리츠) |
| 상장사 목록이 안 갱신됨 | 연결 설정에서 **저장**을 다시 누르면 캐시가 비워집니다 |
| 전 종목 분석 실패 | Worker 주소 끝에 `/health` 를 열어 응답 확인 |

첫 조회는 DART 상장사 목록(약 4천 건)을 받느라 20초쯤 걸리고, 이후에는 하루 동안 캐시됩니다.

## 9. 면책

본 화면의 모든 수치는 공시·시세 데이터의 산술 가공 결과이며 **투자 자문이 아닙니다**.
시나리오 값은 명시된 가정의 계산 결과일 뿐 목표 주가가 아니며,
이 앱은 매수·매도·비중 판단을 제공하지 않습니다. 투자 판단과 책임은 이용자에게 있습니다.
